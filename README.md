# polyclinic
## Программная система поликлиники
В поликлинике работают врачи разных специальностей.
Каждый врач имеет:
- табельный номер (уникальный идентификатор);
- ФИО;
- специальность;
- кабинет.
Пациент имеет:
- идентификатор;
- ФИО;
- дату рождения;
- контактную информацию.
Пациенты записываются на прием к врачам.
В системе хранится расписание приемов и соблюдается контроль отсутствия пересечения записей.
